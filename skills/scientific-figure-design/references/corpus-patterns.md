# 按图型归纳的来源模式

以下是已查看原页支持的范例；需对应图型使用，不把某一配色固定成普遍要求。

- **几何与覆盖图**：P002 Fig.1分层展示资源、地面、轨迹与条带；P003 Fig.3区分通信距离与观测线，Fig.4区分任务点与视场轮廓。复用的是物理关系和图例语义，不能照搬2500 km等参数。[P002, PDF p.3, Fig.1]; [P003, PDF p.6, Figs.3–4]
- **候选/时间图**：P003 Fig.1用对齐区间块对应分段集合；P002 Fig.2把原始和合并窗口置于同轴；P015 Fig.4-6展示排列交叉与重复修复。候选类型必须明确，不能统一称为目标聚类。[P003, PDF p.4, Fig.1]; [P002, PDF p.3, Fig.2]; [P015, PDF p.49, Fig.4-6]
- **框架/反馈图**：P017 Fig.4.1双向连接分配与合成，并将应急处理放在后续；P018 Fig.2.4区分预处理、状态估计和决策。复用“箭头标传递对象、循环表达反馈”，不凭回路认定已证明收敛。[P017, PDF p.38, Fig.4.1]; [P018, PDF p.46, Fig.2.4]
- **协议时序图**：P022 Fig.6.9以参与者生命线和消息箭头展示请求、拒绝、接受、确认及重试。图中有重试不代表存在超时回滚、无死锁或有界通信证明。[P022, PDF p.162, Fig.6.9]
- **效能与代价图**：P003 Figs.5–6把总体价值/代价与参数或个体时序并置；P002 Figs.17–24用统一颜色分组显示收益与CPU；P004 Figs.6、11区分多次运行和迭代轨迹。不要从无误差条图推显著性，也不能把任务完工时刻当算法耗时。[P003, PDF pp.7–8, Figs.5–6]; [P002, PDF pp.11–12, Figs.17–24]; [P004, PDF pp.8/10, Figs.6/11]

来源题名：P002 Continuous monitoring scheduling for moving targets by Earth observation satellites（2023）；P003 Centralized and Distributed Strategies for Handover-Aware Task Allocation in Satellite Constellations（2025）；P004 A Novel Spaceborne SAR Constellation Scheduling Algorithm for Sea Surface Moving Target Search Tasks（2024）；P015《高轨卫星移动目标跟踪任务规划研究》（2020）；P017《对地观测卫星任务规划方法研究》（2023）；P018《天基海洋移动目标监视的联合调度问题研究》（2011）；P022《面向移动目标跟踪的多星协同规划与自主调度研究》（2021）。页码仅对应已审读版本。
