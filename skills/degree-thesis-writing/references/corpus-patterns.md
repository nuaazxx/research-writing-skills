# 学位论文章节组织的有限语料依据

1. **基础接口服务不同决策层。** P018先建立业务与闭环模型，再展开几何/预测/滤波、短期信息调度、长期学习调度，最后恢复部分工程条件做综合仿真。可借鉴“公共接口—独立子问题—综合验证”；不把所有支撑算法归为一个原创算法。[P018, PDF p.32, Fig.1.1]; [P018, PDF pp.45–58, Ch.2]; [P018, PDF pp.146–160, Ch.6]
2. **任务类型可构成并列章节。** P014第三章是观测—数传联合构造，第四章是移动目标概率搜索；两章输入、变量和目标不同。统一论文主题不要求强行共享一个目标函数。[P014, PDF pp.32–43, Ch.3]; [P014, PDF pp.44–52, Ch.4]
3. **划分层次时交代离线与在线。** P022的任务生成、单星图策略、演化分配规则、事件协商各有职责；下游收益用于离线训练不等于运行时持续在线学习，也不等于每次任务分配后进行多轮冲突修复。[P022, PDF p.51, Fig.2.12]; [P022, PDF p.96, Fig.4.8]; [P022, PDF pp.128/131, Figs.5.8/5.10]; [P022, PDF pp.162–163, Figs.6.9–6.10]
4. **综合章保留评估边界。** P018使用轨道资料但重新设定传感器和合成目标；P022用桌面/JADE仿真。系统架构完整、画出协议时序都不自动证明实际部署、实时上界或失效恢复。[P018, PDF pp.149–160, Ch.6]; [P022, PDF pp.166–172, Sec.6.3]

来源标识：P014《多类型观测任务的多星协同规划问题研究》（封面2020）；P018《天基海洋移动目标监视的联合调度问题研究》（2011）；P022《面向移动目标跟踪的多星协同规划与自主调度研究》（封面2021）。P014/P022文件名年份不同，引用以原页书目为准。页码为本次PDF物理页，其他版本须重建映射。这些是结构操作范例，不是通用章数模板或论文正确性背书。
