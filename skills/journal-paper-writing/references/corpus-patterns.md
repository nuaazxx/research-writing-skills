# 文献支持的写作操作

以下是有限语料的操作范例，不是整领域综述，也不要求照搬章节数量。

1. 分层解释输入到决策：运动预测—捕获概率—调度；收益/切换—指派—前瞻/分布式；网格—序列—算子。可借鉴接口组织，但三者对象不同。[P002, PDF pp.3–8]; [P003, PDF pp.2–5]; [P004, PDF pp.3–7]
2. 贡献逐条对应实验：小实例最优参考与大规模实验作用不同；参数扫描、一个模块对照不等于全部模块消融。[P003, PDF pp.5–8, Figs.2/5/6]; [P004, PDF pp.7–10, Figs.6–11]
3. 保留限定词：P002明确不适合高速目标；P003一半界要求收益不小于切换惩罚，不能直接扩展至零收益实例或分布式版。[P002, PDF p.14, Sec.6]; [P003, PDF pp.3/5, Theorems III.3/IV.1]
4. 统计口径需核验：P004的54.77%对应最小值比；P003含归一化惩罚；P002代理相关性不能证明优化等价。借鉴检查方法，不照用这些数值。[P004, PDF p.8, Sec.IV-B1]; [P003, PDF p.7, Fig.5]; [P002, PDF pp.9–10, Sec.5.2.2/Figs.11–12]
